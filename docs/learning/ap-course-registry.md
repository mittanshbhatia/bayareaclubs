# AP course registry

Original BayAreaClubs AP catalog. `source_basis` is **ORIGINAL** for every shipping course.
Public CED / framework **codes** may appear as metadata. CED prose, College Board items, Stellar Learning, and Unlimited Voices banks are not used.

Catalog UI section types (original Peninsula layout, not a pixel clone): filters/families, progress, featured, course tiles. Tile rhythm: media, title, status, one action. Course homes at `/dashboard/learn/ap/[slug]` include header, progress, unit map, continue, practice, weak areas, recent results, and tools.

Tools on shipping courses: practice, quiz, review, notes, readiness.

Card art is original 2× geometric SVG (592×224, Peninsula green/teal), displayed at the owner-catalog media frame (254×80 inside 288×242 tiles). Storage path pattern: `course-assets/learn/<namespace>/card-2x.svg` (private, signed). No Stellar screenshots, video, HTML, or lesson text are committed.

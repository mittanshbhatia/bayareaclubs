# Product Documentation

BayAreaClubs supports accountable club creation and operations for students and
authorized adults across multiple schools.

Student profiles, contact information, attendance, rosters, and private club media
are not public product surfaces. Under-13 registration requires a future
school-managed or guardian-authorized onboarding flow. Compliance-supporting
controls require institutional and legal review and are not a claim of automatic
COPPA or FERPA compliance.

Add reviewed workflow specifications and acceptance criteria in this directory
before implementing each domain capability.
